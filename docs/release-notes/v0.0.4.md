# PublishStudio v0.4.0

首个公开发布版本。把 .NET WebAPI / Node.js 项目的**编译、压包、上传 OSS、登记发布记录**串成一条固定流水线：选中项目点一次，剩下的它跑完。

## 亮点

- **一条流水线走完发版** —— 查发布信息 → 正式环境二次确认 → 编译 → 压成 zip → 后置命令 → 上传 OSS → 回调登记 → 清理产物，八步顺序固定。
- **编译前先验前置条件** —— 缺接口地址 / OSS 凭据 / 登录状态 / 发布 ID 会在**编译开始前**报错，不白跑一次编译。
- **正式环境二次确认** —— 发布信息里 `isProduce == true` 时弹「⚠️ 发布确认（危险操作）」，点「否」直接中止。
- **托盘常驻** —— 按项目自定义分组排菜单，随时「运行 / 发布 / 编译」，正在跑任务的项目带 `(发布中)`。
- **内嵌发布记录页** —— WebView2 窗口直接打开当前项目的发布记录，不用切浏览器。
- **本地留包** —— 编译产物会清理，但 `publish-zip` 里的 zip 保留，方便手工分发。

## 下载哪个包

| 包 | 适合谁 | 前提 | 体积 |
|---|---|---|---|
| `PublishStudio-0.4.0-win-x64.zip` | 大多数人 | 无需装 .NET | 58.8 MB |
| `PublishStudio-0.4.0-win-x64-fd.zip` | 在意体积 | 需 .NET 8 **Desktop** Runtime | 845 KB |
| `PublishStudio-0.4.0-setup.exe` | 想要开始菜单和卸载项 | 无需装 .NET，装到 `C:\Program Files\PublishStudio` | 59.4 MB |

三个包功能一致。包内都带 `使用说明.txt`，开篇按包类型分别讲运行步骤。

## 系统要求

- 64 位 Windows 10 / 11
- WebView2 Runtime：Win11 自带；Win10 未装时「打开发布记录」会提示，装一次即可
- 要编译 .NET 项目需要 .NET SDK 8；要编译 Node.js 项目需要 Node.js + npm

## 已知限制

- 发布信息查询与发布记录登记依赖内务府（NWF）接口和指定的 OSS 桶。**没有这套内部系统时，「发布打包」走不通，只有「运行 / 编译」能用。**
- 流水线顺序固定，不能增删步骤。
- `settings.json` 中的 OSS 密钥为明文存储。
- 没有代码签名，首次运行会出现 SmartScreen 提示（「更多信息 → 仍要运行」）。

## 升级

- **zip 版**：托盘右键退出 → 用新的 exe 覆盖旧的 → 重新打开。
- **安装版**：直接运行新版 `setup.exe` 覆盖安装，`AppId` 相同会识别为升级。

配置（`%LOCALAPPDATA%\PublishStudio`）和日志都不会丢。
