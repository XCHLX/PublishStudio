发布工具 使用说明
========================================

〇、先确认你拿到的是哪一种
  A  自包含版    PublishStudio-<版本>-win-x64.zip
     解压即用，不用装 .NET，包比较大（约 60 MB）。看「一、A」。
  B  依赖环境版  PublishStudio-<版本>-win-x64-fd.zip
     包很小（约 2 MB），但要先装 .NET 8 桌面运行时。看「一、B」。
  C  安装版      PublishStudio-<版本>-setup.exe
     双击安装，自带开始菜单和卸载项，内部就是自包含版。看「一、C」。

  三种装好之后功能完全一样，只是分发方式、体积和依赖不同。


一、怎么运行

  A 自包含版
    1. 先「全部解压缩」到硬盘上的固定文件夹，比如 D:\Tools\PublishStudio
       不要在压缩包预览窗口里直接双击 exe —— 那样 Windows 只会临时解出
       exe 一个文件，会提示「这个应用程序可能要靠这个文件夹中其他压缩文件
       才能运行」，而且临时目录会被系统清理，升级也不方便。
    2. 双击 PublishStudio.exe
    3. 不用安装，也不用装 .NET。

  B 依赖环境版
    1. 先装 .NET 8 桌面运行时（Desktop Runtime，x64），约 55 MB
       https://dotnet.microsoft.com/download/dotnet/8.0
       必须是「Desktop Runtime（桌面运行时）」。只装 Runtime 或
       ASP.NET Core Runtime 不够，会报缺 Microsoft.WindowsDesktop.App。
       装完可验证：命令行执行 dotnet --list-runtimes，
       应能看到一行 Microsoft.WindowsDesktop.App 8.0.x
    2. 再「全部解压缩」到固定文件夹（同样不要直接在压缩包里双击）
    3. 目录里的 WebView2Loader.dll 必须留着，删了「打开发布记录」会失败。
       exe 单独拷走能启动，但那个功能就用不了。
    4. 双击 PublishStudio.exe

  C 安装版
    1. 双击 setup.exe，一路下一步。会弹 UAC 提权（要装到 C:\Program Files），
       需要用管理员账号确认一下。
    2. 默认装到  C:\Program Files\PublishStudio
       会建：开始菜单里的「PublishStudio 发布工具」组（含程序、使用说明、
       卸载入口），以及桌面快捷方式（默认勾选，可以取消）。
    3. 最后一步可以勾「立即运行 PublishStudio」直接启动。
    4. 内部是自包含版，不用另装 .NET。
    5. 卸载：「设置 → 应用 → 已安装的应用」里找 PublishStudio，
       或开始菜单里的「卸载 PublishStudio」。
       卸载只删程序目录，配置和日志不会动（位置见第四节）。


二、第一次使用要配三样
  1. 菜单「设置 → 发布配置」里填：接口地址、网页地址、OSS Key、OSS 密钥
  2. 右上角「登录」，用内务府账号登录一次
  3. 「文件 → 新建项目」把项目目录加进来（路径里有中文、空格都没关系）


三、这台机器还需要什么
  三种包共同的：
  - WebView2 Runtime  Win11 自带；Win10 没装的话「打开发布记录页面」会提示，
                      装一次就好
  - 网络              能访问内务府接口和阿里云 OSS

  另外按你要做什么决定：
  - .NET SDK 8        要编译 .NET 项目必须有（只装运行时不够，编译要 SDK）
  - Node.js + npm     要编译 Node.js 项目必须有
  - git               要用右键「git pull」才需要，并且得在 PATH 里

  只有依赖环境版（B）还需要 .NET 8 桌面运行时；自包含版（A）和安装版（C）
  已经把运行时打进 exe 里了，不用另装。

  系统要求：64 位 Windows 10 / 11。


四、数据和日志在哪
  配置     %LOCALAPPDATA%\PublishStudio\projects.json、settings.json
  日志     %TEMP%\PublishStudio\Logs\         （只保留 1 天）
  临时产物 %TEMP%\PublishStudio\build\        （按「设置」里的天数保留）
  菜单「帮助」里有打开这些目录的入口。

  三种运行方式用的是同一份配置：先用 zip 版再换成安装版，
  项目和设置都还在，不用重新配。


五、升级
  A / B（zip 版）
    先右键托盘图标 →「退出」，再用新的 exe 覆盖旧的，然后重新打开。
    配置、日志都不会丢。
  C（安装版）
    直接运行新版本的 setup.exe 覆盖安装就行，安装程序认得出是同一个程序
    （AppId 相同），会当成升级装在原目录、保留快捷方式，配置也不会丢。
    不需要先手动卸载旧版。


六、注意
  1. settings.json 里的 OSS 密钥是明文，别把 %LOCALAPPDATA%\PublishStudio
     整个目录发给别人。
  2. 第一次运行如果弹「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」。
     exe 和 setup.exe 都没有代码签名，这属于正常提示。
  3. 关窗口只是缩到右下角托盘，真正退出要走托盘菜单的「退出」。
  4. 依赖环境版报「缺少 .NET 运行时 / Microsoft.WindowsDesktop.App」时，
     说明桌面运行时没装或版本不对，按「一、B」第 1 步装一次即可；
     或者干脆改用自包含版，什么都不用装。
